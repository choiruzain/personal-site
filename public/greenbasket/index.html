    About this case

    Students design a data warehouse across the four source systems to answer three board questions: why basket value is falling, what drives fresh produce waste, and whether the loyalty program pays for itself.

    This page shows only the symptoms the board already knows about. The breakdowns that answer those questions are left for students to find.

    Built by Choiru Za'in with Python (pandas) and plain HTML and SVG. See the data generator on GitHub.

    Synthetic data, generated with seed 3003 for January 2024 to June 2026.
